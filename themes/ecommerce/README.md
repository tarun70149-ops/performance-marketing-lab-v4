# DODSCommerce Fresh Theme
Upload the contents of this folder to `themes/ecommerce/` after deleting the old ecommerce theme.
50 product pages: DODS001.html–DODS050.html.
Core paths are intentionally relative:
- Product -> `cart.html`
- Cart -> `checkout.html`
- Checkout -> `thank-you.html`
- Product links -> direct `DODSxxx.html`
- Marketing Tools -> `catalog-exporter.html`
Cart data uses browser localStorage.
No Meta Pixel, GTM, GA4, Google Ads tag or CAPI is installed.
